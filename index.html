Workshop 2 · Designing Digital-Remote Interactions · Studio task

One Small Gesture

Make a piece where a small gesture on a phone becomes a mark on your laptop screen. Anyone can join by scanning the QR code, so at the show and tell the audience draws the picture together.

Four steps, all in the p5.js web editor. Nothing to download or install. You only change one tab: sketch.js.

1Make your own copy

  1. Open the starter sketch. It opens in the p5.js editor.
  2. Log in (top right), or sign up for a free account. You need to be logged in to save.
  3. Choose File → Duplicate. This is now your copy. Click the pencil next to its name and call it One Small Gesture.
  4. Press Play (▶). Drag on the preview with your mouse: marks appear. Your mouse works like a phone, so you can test without one.

Open the file list with the small arrow (>) at the top left of the code. You'll see index.html, room.js and sketch.js. Only change sketch.js.

2Join with your phone

  1. Scan the QR code in the corner of your screen with your phone's camera.
  2. Your phone becomes a touch pad. Touch it and drag: the marks appear on the laptop.
  3. Ask the people next to you to scan it too. Each phone gets its own colour.

The phone and the laptop don't need to be on the same Wi-Fi. Each time you press Play, phones lose the link for a moment and reconnect by themselves after a few seconds.

3Make it yours

In the sketch.js tab there are three marked parts. For B and C, pick one option, copy it, and paste it over that whole part, from its /* ===== line down to its END line. Press Play to see the change, and File → Save (Ctrl/Cmd+S) often.

A · About

Change the title, your name, the prompt (it appears on every phone), and the colours.

B · Gesture: which touches make a mark

Touch and drag. Faster drags make bigger marks.

/* ===== B · GESTURE ============================================ */
// DRAG: touch and drag. Faster drags make bigger marks.
function fingerDown(f) {
  addMark(f.x, f.y, 0.4, f.hue);
}

function fingerMove(f) {
  addMark(f.x, f.y, map(f.speed, 0, 40, 0.15, 1, true), f.hue);
}

function fingerUp(f) {}
/* ===== END B ================================================== */

The gesture of the feed. Swipe up and down on the phone; each phone draws down its own column.

sketch.js · replaces all of part B
/* ===== B · GESTURE ============================================ */
// SCROLL: swipe up and down. Each phone draws down its own column.
let scrollY = {};

function fingerDown(f) {}

function fingerMove(f) {
  const y = (scrollY[f.hue] ?? height / 2) - f.dy * 3;
  scrollY[f.hue] = ((y % height) + height) % height;        // wrap around the screen
  const x = width * (0.1 + (f.hue / 360) * 0.8);           // this phone's column
  addMark(x, scrollY[f.hue], map(abs(f.dy), 0, 60, 0.1, 1, true), f.hue);
}

function fingerUp(f) {}
/* ===== END B ================================================== */

C · Response: what a mark looks like

Each mark spreads out as a ring, then leaves a dot.

sketch.js · replaces all of part C
/* ===== C · RESPONSE =========================================== */
// RIPPLES: each mark spreads out as a ring, then leaves a small dot.
const LIFE = 1600;   // how long a mark animates, in ms

function animate(m, age) {            // runs every frame while age goes 0 → 1
  const r = 20 + m.size * 220 * age;
  noFill();
  stroke(m.hue, 70, 100, 1 - age);
  strokeWeight(1 + m.size * 4 * (1 - age));
  circle(m.x, m.y, r * 2);
  circle(m.x, m.y, r * 1.2);
}

function settle(m, g) {               // runs once: what stays on the picture
  g.noStroke();
  g.fill(m.hue, 60, 100, 0.55);
  g.circle(m.x, m.y, 4 + m.size * 14);
}
/* ===== END C ================================================== */

Each mark opens into a flower. The outlines stay behind and layer into a garden.

sketch.js · replaces all of part C
/* ===== C · RESPONSE =========================================== */
// BLOOMS: each mark opens into a flower and leaves its outline behind.
const LIFE = 2200;

function animate(m, age) {
  const petals = 5 + floor(m.size * 7);
  const r = (30 + m.size * 120) * (1 - pow(1 - age, 3));    // ease out
  push();
  translate(m.x, m.y);
  rotate(age * 0.6);
  noStroke();
  fill(m.hue, 60, 100, 0.1 + 0.35 * (1 - age));
  for (let i = 0; i < petals; i++) {
    rotate(TWO_PI / petals);
    ellipse(r * 0.5, 0, r, r * 0.35);
  }
  pop();
}

function settle(m, g) {
  const petals = 5 + floor(m.size * 7);
  const r = 30 + m.size * 120;
  g.push();
  g.translate(m.x, m.y);
  g.rotate(0.6);
  g.noFill();
  g.stroke(m.hue, 50, 100, 0.3);
  g.strokeWeight(1);
  for (let i = 0; i < petals; i++) {
    g.rotate(TWO_PI / petals);
    g.ellipse(r * 0.5, 0, r, r * 0.35);
  }
  g.pop();
}
/* ===== END C ================================================== */

Each mark links to marks already near it, whoever made them. No one draws the network; it emerges.

sketch.js · replaces all of part C
/* ===== C · RESPONSE =========================================== */
// CONSTELLATION: each mark links to the marks already near it, from anyone.
const LIFE = 1400;
const REACH = 140;   // how far a link can reach, in pixels

function nearby(m) {
  return settled
    .filter((o) => o !== m && dist(m.x, m.y, o.x, o.y) < REACH * (0.5 + m.size))
    .slice(-12);
}

function animate(m, age) {
  const k = min(1, age * 2);
  for (const o of nearby(m)) {
    stroke(o.hue, 40, 100, (1 - age) * 0.8);
    strokeWeight(1);
    line(m.x, m.y, lerp(m.x, o.x, k), lerp(m.y, o.y, k));
  }
  noStroke();
  fill(m.hue, 70, 100);
  circle(m.x, m.y, 8 + m.size * 20 * (1 - age));
}

function settle(m, g) {
  for (const o of nearby(m)) {
    g.stroke(m.hue, 40, 100, 0.2);
    g.strokeWeight(1);
    g.line(m.x, m.y, o.x, o.y);
  }
  g.noStroke();
  g.fill(m.hue, 60, 100, 0.9);
  g.circle(m.x, m.y, 3 + m.size * 6);
}
/* ===== END C ================================================== */

To tune it, change one number at a time: LIFE is how long a mark animates; the bigger numbers in animate() and settle() set the size.

4Show it

  1. Save, then choose File → Share and copy the Fullscreen link. Open it in a new tab: your sketch fills the page, without the code.
  2. Make the browser full screen: Ctrl+Cmd+F on a Mac, F11 on Windows.

If something isn't working

The phone says "waiting for the laptop sketch to run…".

Your sketch has stopped. Press Play on the laptop.

The phone says "connecting to the internet…", or the laptop corner says "reconnecting".

That device has lost its connection, or the network blocks it. Try the phone on mobile data. Your mouse still works on the laptop.

Nothing changed after I pasted.

Press Play again. The editor only reruns your sketch when you press it, unless Auto-refresh is ticked.

The preview is blank after pasting.

Look at the console under the code. A red error usually means a /* ===== line was deleted or pasted twice.

"Duplicate" is greyed out, or my work disappeared.

You weren't logged in. Log in, open the starter sketch again, and duplicate it.
